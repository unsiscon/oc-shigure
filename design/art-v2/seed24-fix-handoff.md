# seed24-fix：无多模态 Agent 交接

## 这次交付是什么

这是 `regular / idle / frame 1` 的 24×24 单帧修正版，不是七状态最终资产，也不是运行时接口变更。任务书里的 “frame 1” 在当前 TypeScript 数组中对应 `frameIndex: 0`；接入时必须先确认项目的帧编号约定。

## 唯一源稿

`seed24-fix-grid.txt` 是唯一可编辑源稿，必须保持恰好 24 行、每行 24 个字符，只允许 `.0123456789ab`。`seed24-fix-data.json` 是同一网格的机器可读副本；两者不一致时，以网格文件为准并重新生成 JSON/预览。

PNG 仅用于视觉复核，不能被运行期解码，也不能让无多模态 Agent 依据 PNG 重新猜画稿。

## 图例

字符是 `.0123456789ab` 在 `ROW_CHARS` 中的直接位置：

| 字符 | 语义 |
|---|---|
| `.` | 透明 |
| `0/1/2` | 发影 / 发基 / 发亮 |
| `3` | 皮肤 |
| `4/5` | 蓝眼 / 深瞳 |
| `6` | 制服 |
| `7` | 暖白边 |
| `8` | 红领结/红裙边 |
| `9` | 黑袜 |
| `a` | 深红棕短靴 |
| `b` | 最外层深色轮廓 |

## 无图阅读重点

从上到下阅读时，应能识别以下结构：

1. y=2–17 是宽而圆的深棕长发，外侧不是细窄柱状轮廓。
2. y=5–10 中央是小椭圆脸；左右各有蓝眼簇，`4` 为亮蓝，`5` 为深瞳。
3. 右侧 x≈19–21 的棕色连续像素是单条细辫，不是第二条马尾。
4. y=10–15 是深色水手服：两侧 `7` 为暖白侧板，中间 `8` 是红色长领结/裙边。
5. y=17–18 是左右分开的 `9` 黑袜；y=19–22 是更厚、更圆的左右 `a` 短靴，中间必须留透明间隙。这是本轮 Q 版修订的重点：减少细长腿感。
6. `b` 只出现在角色最外层剪影，不应被改成内部网格线或悬浮装饰。

## 接入边界

本次没有修改 `src/`、`scripts/` 或 OpenCode 运行时。开发 Agent 后续接入时，只应把这份网格转换成现有 `PixelFrame` 数据，并保持调色板索引不变；不要重新设计角色、不要读取 PNG、不要把本单帧误当作七状态完成品。

## 验收命令

```bash
npx tsx scripts/audit-art-noise.ts \
  --grid design/art-v2/seed24-fix-grid.txt \
  --size regular --frame idle
```

预期结果为 `AUDIT: 1 frame(s), 0 violation(s)`。视觉验收仍需人工对照 `design/art-v2/shigure-v3-master-crop.png`；本文件只能降低无多模态 Agent 的误读，不能替代视觉 gate。
